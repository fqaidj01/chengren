## 🚀 1 分钟一键部署到 GitHub Pages

1. 在 GitHub 上新建一个仓库（例如命名为 `stargps-nav`）；
2. 将本目录下的所有文件（`index.html`、`README.md`、`.nojekyll` 等）推送到该仓库的 `main` 分支；
3. 进入仓库设置 **Settings** ➔ 找到左侧 **Pages** 选项卡；
4. 在 **Build and deployment** 下方的 **Branch** 选择 `main` 分支和 `/(root)` 目录，点击 **Save**；
5. 等待 30 秒即可通过 `https://<你的GitHub用户名>.github.io/stargps-nav/` 全球高速访问！
